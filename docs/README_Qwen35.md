# EPANET-AI — Qwen3.5-4B GGUF

Это экспериментальный запуск базовой Qwen3.5-4B-Q4_K_M через отдельный локальный llama-server. Он не обучает модель и не использует адаптер Qwen2.5. Качество, память и скорость на конкретном ПК ещё не проверены.

## Что запускать

1. Поместите CSV и не более одного INP в `data/имя_города/`. В ноутбуке «Обработка» выполните клетки 1–3, чтобы обновить полный набор сводок.
2. В ноутбуке «Обучение» выполните клетки 1, 2, 3. Первая ячейка по историческим причинам печатает настройки старого ученика Qwen2.5: они относятся к старому обучению, НЕ к модели отчёта.
3. В клетке 9 задайте `TARGET_CITY_OR_PATH = "имя_города"`. Если INP не найден автоматически, укажите `GEOMETRY_INP_PATH`. Запустите клетку 9. Первый запуск скачает модель из `unsloth/Qwen3.5-4B-GGUF` и Windows x64 бинарники llama.cpp с официального GitHub; нужен интернет и несколько ГБ свободного места. Последующие запуски используют скачанные файлы.
4. Клетки 4–8 и OpenRouter не нужны для базовой модели. Клетки 6–7 НЕ обучают Qwen3.5-4B, а старый адаптер от Qwen2.5 несовместим с ней.
5. HTML, обработанный Markdown и сырой вывод — в `reports/`. Схема строится в исходных координатах INP; без подтверждённой системы координат она не географическая карта.

## Память и скорость

Начальный `LLAMA_BACKEND = "cpu"` использует CPU (и оперативную память), а не RTX; это сознательный осторожный вариант. Для пробы ускорения на NVIDIA укажите `LLAMA_BACKEND = "cuda"`; будет скачан CUDA 12.4 llama.cpp и cudart. `LLAMA_N_GPU_LAYERS = 16` — начальная настройка, не гарантия, что у вас поместится. При ошибке драйвера/памяти вернитесь к `cpu` или уменьшите слои. На других ОС задайте путь к актуальному llama-server явно через `LLAMA_SERVER_PATH`. Выделенный локальный сервер завершается после генерации.

Контекст `LLAMA_CONTEXT=16384` включает промпт и ответ. `INFERENCE_MAX_NEW_TOKENS=8192` — верхний предел, а не обещание полного отчёта. При нехватке памяти уменьшите контекст и лимит; при обрыве система сообщит об этом. В зависимости от установленной версии llama.cpp и железа могут потребоваться другие настройки.

## Датасет

Сначала сравните базовую модель на нескольких городах и вручную проверьте давление, единицы, ID, QH, отсутствие данных, повторы и Markdown. Старые ответы Учителя можно сохранить и отобрать, но в них были спорные утверждения; не считайте их эталоном автоматически. Выделите целые города для независимого теста, исправьте гидравлические вычисления и сформируйте проверенные инженером примеры. Только после измерения качества решайте вопрос отдельного SFT для Qwen3.5; старые клетки не поддерживают его и не гарантируют результат. Повторно генерировать весь датасет за деньги сразу не требуется.

Проверены компиляция ячеек, существующие тесты обработки и поток обмена с имитатором llama-server; реальная модель, Windows CUDA, расчёт на полном наборе CSV и точность инженерных выводов не проверялись. По умолчанию отчёт — черновик для проверки специалистом. Данные графиков передаются модели в текстовом виде; она не рассматривает сами изображения. Старый HTML-шаблон содержит предположения, которые необходимо проверять.
